# Sound-Blaster-Command-Switcher


This program adds an icon in the taskbar allowing you to switch from headphones to speakers by double-clicking on it so you don't have to open Sound Blaster Command anymore to switch.

the program checks wether speakers or headphones are the current output, to display the proper icon.

it starts automatically on startup (it adds a "run" registry key for this purpose)

you can also use the shortcut ctrl+alt+* to switch

The program is offline and does not retrieve any information
Download all the files from the repository and install by runing install.ps1
